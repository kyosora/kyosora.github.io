如何快速查詢資料庫檢視表(View)的欄位資訊

今天遇到長官要求提供所需的資料訊息，因為要求的資料欄位是由多個資料表組合而成，要一個一個去查看原始資料表相當費時。本文介紹如何用 SQL 直接查出檢視表的欄位資訊。

各資料庫系統的查詢方式

Microsoft SQL Server

sys.columns.max_length 原始值是 byte 數；上面的查詢已把 nchar／nvarchar 除以 2，並保留 -1 表示 varchar(max)／nvarchar(max)。schema 條件也不能省，同一個資料庫可能同時有 dbo.Report 和 audit.Report。

View 的輸出欄位不會繼承底層資料表的 default constraint，所以這裡刻意不查 DefaultValue。如果文件還要交代來源欄位與預設值，必須另外分析 View 定義與相依關係；單靠 sys.columns 無法可靠還原每個輸出欄位的 lineage。

查詢結果說明

欄位 說明
Column Name 欄位名稱
Data Type 資料型態，如 varchar、int、decimal
Max Length 文字型態的最大長度
Numeric Precision 數值型態的精確度
Numeric Scale 小數位數
Is Nullable 是否允許 NULL

查詢結果可以直接匯出成 Excel，足夠處理這次「交出 View 欄位清單」的需求。若對方要的是資料來源、計算公式或底層 constraint，就要再讀 View 定義；那已經是另一份規格，不能從這張欄位表硬推。
